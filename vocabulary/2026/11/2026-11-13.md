## 语法：feel 与 feel like

feel /fiːl/ 的词形为 feel → feels → felt → felt → feeling。搭配不同，意思也不同。

以下为补充例句（非用户原句）。

- **feel + 形容词** 描述感受。I feel relaxed.（我感觉很放松。）事物作主语时也可描述触感，如 This blanket feels soft.（这条毯子摸起来很软。）
- **feel + 名词** 表示感受到某事物。I felt a sharp pain.（我感到一阵剧痛。）
- **feel like + doing** 表示当下想做某事。I feel like relaxing.（我想放松一下。）
- **feel like + 名词** 可表示“感觉像”或“想要”，由语境决定。I feel like a fool.（我觉得自己像个傻瓜。）I feel like some coffee.（我想喝点咖啡。）
- **feel like + 从句** 在口语中常表示“感觉好像”。I feel like I’m dreaming.（我感觉自己像在做梦。）feel (that) + 从句也可表达看法，例如 I feel (that) we should wait.（我觉得我们应该等等。）

### 其他常用搭配

**feel (that) + 从句** 和 **feel like + 从句** 都成立。前者常表达主观判断，that 可以省略。后者常见于口语，可以表达类似的判断，也可描述一种印象或体验。补充例句（非用户原句）：**I feel (that) we should wait.**（我觉得我们应该等等。）**I feel like we should wait.**（我感觉我们还是等等比较好。）两句意思接近，第二句更口语化。**I feel like I’m dreaming.**（我感觉自己像在做梦。）这里 like 从句表达体验，而 **I feel like going out.**（我想出门。）是 like + doing，表达意愿。

以下为补充例句（非用户原句）。

- **feel for someone** 表示同情某人。I really feel for her.（我真的很同情她。）feel for 也可表示伸手摸索，如 I felt for the light switch in the dark.（我在黑暗中摸索电灯开关。）
- **feel up to doing something** 表示觉得自己有精力或状态去做某事。I don't feel up to going out tonight.（我今晚没精神出门。）I don't feel like going out tonight. 则表示“我今晚不想出门”。
- **feel + 宾语 + 动词原形或 -ing** 表示感知某事发生。I felt the floor shake.（我感觉地板晃了一下。）I could feel the floor shaking.（我能感觉到地板在晃。）
- **It feels like ...** 可描述环境或体验给人的感觉。It feels like spring today.（今天感觉像春天。）It feels like we’ve been waiting for hours.（感觉我们已经等了好几个小时。）
- **feel free to do something** 用来表示许可或邀请。Feel free to ask questions.（有问题尽管问。）
