# Connected Speech: Vowel-to-Consonant, Consonant-to-Consonant, Consonant-to-Vowel, and Vowel-to-Vowel Linking

## 问题背景

逐个单词都能读准，并不等于整句话会自然。若每个词之间都重新停气、重新起音，句子会显得断裂；反过来，如果整句话从头黏到尾，又会失去信息边界。

**Connected Speech（连贯语流）**的关键不是“一口气说到底”，而是先把句子划分成小的语块，再让同一语块内的声音保持连续：

```text
语块内部：连接单词，不随意停气
语块之间：允许短暂停顿或换气
```

本节不重点讨论怎样划分语块，而是解决一个更具体的问题：语块内部相邻单词的边界处，声音应当怎样从前一个词过渡到后一个词。

## 先按声音分类，而不是按字母分类

视频使用一个便于练习的简化模型：

- **Vowel（元音）**：气流可以较自由地流出；
- **Consonant（辅音）**：气流受到完全或部分阻碍。

视频用 `ei`、`a`、`ee`、`ow`、`uw` 表示若干元音听感，并以 `k`、`ch`、`r`、`th`、`y`、`w` 等说明辅音。这里讨论的是实际发出的声音，不是单词最后或最前面的书写字母。

相邻两个词因此形成四类连接：

| 类型 | 前词末音 | 后词首音 | 核心动作 |
| --- | --- | --- | --- |
| Vowel-to-Consonant | 元音 | 辅音 | 元音直接流向辅音位置 |
| Consonant-to-Consonant | 辅音 | 辅音 | 辅音位置连续转换，不插入元音 |
| Consonant-to-Vowel | 辅音 | 元音 | 前词末辅音在听感上连接后词首元音 |
| Vowel-to-Vowel | 元音 | 元音 | 合并相近元音，或用自然滑音过渡 |

## Vowel-to-Consonant：从流动元音直接进入辅音

当前一个词以元音音素结尾、下一个词以辅音音素开头时，元音保持流动，口腔直接进入后一个辅音的位置。这通常是四类组合中较容易的一类。

```text
play fair
see them    → ee + th
```

重点不是把两个词读快，而是避免在元音结束后停气，再单独启动下一个词。

## Consonant-to-Consonant：不加元音，直接换位置

连续辅音对某些学习者更有挑战，因为其母语可能不常出现多个辅音紧邻的情况。常见补偿动作是：

- 在两个辅音之间添加一个元音；
- 读完第一个词后停顿，再重新启动第二个词。

两种做法都会打断语块。正确方向是保持气流组织的连续性，让口腔从第一个辅音位置直接过渡到第二个辅音位置。

### 相同辅音：共享一次位置

如果前词末尾和后词开头是同一个辅音，不需要完整释放两次。到达第一个辅音的位置后，保持这个位置，再进入后面的声音。听感可以是一个略长的辅音，也可以近似只有一个辅音。

```text
cheap prices → chea-prices     # p + p
big gate     → bi-gate         # g + g
real lesson  → rea-lesson      # l + l
gas station  → ga-sstation     # s + s
```

这些写法只是视频提供的 **respelling（听感提示拼写）**，作用是显示连接位置，不是标准拼写或 IPA。

### 不同辅音：连续换位

两个辅音不同时，仍然不要添加过渡元音：

```text
bar crawl
mixed nuts
harsh reality → har-shree-a-l’dee
wine glass    → wai-nglass
```

`bar crawl` 不应读成 `bar a crawl`。`wine glass` 中，`n` 与 `g` 紧密衔接，整体听起来近似一个长词。

`mixed nuts` 的屏幕提示写作 `miks-t-nuts`，但实际示范中没有清楚读出 `t`，听感更接近 `miks-nuts`。这说明提示拼写不能机械理解为每个辅音都要单独释放；本例的重点是不要插入元音，也不要在两个词之间停顿。

## Consonant-to-Vowel：让末辅音连接后面的元音

当前一个词以辅音结尾、后一个词以元音开头时，前词末辅音会在听感上成为后面音节的起始音。单词的拼写边界没有改变，但听感上的音节边界发生了重新分组。

```text
work ethics → wor-kethics → were-keh-thiks
finish it   → fini-shit
```

如果需要重读或拉长前一个词，应延长其中的主要元音，不要拖长末尾辅音。末辅音仍需轻快地连接后面的元音。

### 多个连接可以同时出现

`one mile away` 同时包含两种边界：

```text
one mile away
→ one-mai-laway
→ wa-nmai-luh-way
```

- `one → mile` 是不同辅音 `n + m` 的连续转换；
- `mile → away` 是末尾 `l` 与后面元音的连接。

完整语块中也会连续发生多个过程：

```text
Can I get a wine glass, please?
→ ca-nai-ge-da-wai-nglass / please
```

从 `Can` 到 `glass` 构成一个连续语块，`please` 前可以形成语块边界。`get a` 中的 `t` 在示范里听起来接近快速、轻短的 `d`，属于美式英语中常见的 **flap（闪音）**。

画面中 `about it` 的标题与下方 `whuh-duh-baw-d’t` 的提示并不完全对应；后者更像完整短语 `what about it` 的听感。笔记保留这项差异，不把不完整画面强行解释成唯一读法。

## Vowel-to-Vowel：合并或滑过元音边界

两个元音相遇时，口腔不需要在词界处关闭并重新启动。具体连接取决于两个元音的相似程度和舌位移动方向。

### 相同或相近元音：连成一个长音

```text
we each    → weeeeech
law office → lawwwfis
```

前后元音相同或接近时，可以把它们连成一个持续的声音。这里的“连成一个音”描述的是听感连续性，并不表示两个单词在语法上合并。

### 后元音过渡：出现 W 滑音

以 `uw`、`ow` 一类后元音结尾，再连接另一个元音时，口腔过渡中常出现类似 `w` 的滑音：

```text
you always → yuw-(w)aa-ways
who is it  → who-wi-zit
go about   → go-(w)a-bawt
```

### EE 类元音过渡：出现 Y 滑音

`ee` 类元音连接另一个元音时，过渡中常出现类似 `y` 的滑音：

```text
see it      → see-(y)it
she always  → shee-(y)aa-ways
she already → shee-(y)aa-ready
we are here → wee-(y)ar-here
```

括号中的 `(w)` 和 `(y)` 都是自然过渡产生的听感，不是原词拼写中新增的字母。

## Coalescent Assimilation：两个辅音融合成新音

有些辅音连接不只是平滑换位，而会融合为一个新的声音。视频补充了两组常见组合。

### T + Y → CH

```text
can’t you → can-chyou
won’t you → wow’n-chyou
get your  → ge-chy’r
```

词尾 `t` 与后词开头的 `y` 相遇时，可以融合为 `ch / tʃ`。

### D + Y → J

```text
did you   → di-djuw
hide your → hai-dj’r
```

词尾 `d` 与后词开头的 `y` 相遇时，可以融合为 `j / dʒ`。

视频有一处字幕将该条件写成“下一个词以 y 结尾”，但规则和所有例子都表明应是“下一个词以 y 音开头”。

## 连贯不等于没有停顿

“保持声音连续”只适用于同一语块内部。**Phrasing（意群划分）**仍然决定哪里应当停顿、换气或重置语调。

```text
句子
→ 按意义划分语块
→ 识别每个语块内的声音边界
→ 使用相应连接动作
→ 语块内连续，语块间留缝
```

因此，“不要追求每个词都特别清楚”不是要求含糊，而是不要通过逐词停顿制造清晰度。自然表达的清晰来自合理的语块边界、重音和上下文，而不是把每个书写空格都读成停顿。

## 练习方法

1. 找出自己觉得困难的连接，先判断它属于四类中的哪一类。
2. 选择一小段文本，按意义把句子划分为语块。
3. 标出语块内相邻单词的末音与首音。
4. 单独慢练连接处，避免插入额外元音或停止气流。
5. 把连接处放回完整语块，让整个语块近似一个长词。
6. 最后恢复语块之间的微停顿和换气，不要把整句无边界地黏在一起。

## 回到问题

逐词朗读之所以听起来生硬，是因为说话者按照书写空格反复停止并重新启动声音。连贯语流则按照语音条件重新组织词界：相同辅音可以共享位置，不同辅音直接换位，末辅音可以连接后面的元音，两个元音之间可以合并或产生滑音，某些辅音组合还会融合成新音。

最终目标不是记住所有提示拼写，而是形成一个可复用的判断过程：

```text
先划语块
→ 再看末音与首音
→ 选择连接动作
→ 保持语块内部连续
```

## 要点小结

- 连贯语流是“语块内连接、语块间留缝”，不是整句不换气。
- 判断连接类型要依据实际声音，而不是单词的书写字母。
- 辅音之间不要为了方便而插入额外元音。
- 辅音接元音时，听感上的音节边界可以跨越单词边界。
- 元音接元音时，相近元音可以合并，也可能自然出现 W 或 Y 滑音。
- `t + y` 和 `d + y` 可以分别融合为 `ch` 和 `j` 音。
- 视频的 respelling 用于提示听感，不是标准音标；实际示范应优先于画面中的机械分隔。
